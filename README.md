## 🚀 Featured Project

### 📱 ZTE U10S Pro SMS Manager

A standalone Windows application for managing SMS directly through the **ZTE U10S Pro modem API** — without relying on the modem's browser interface.

**Highlights:**

- 🔐 Challenge/hash based modem authentication
- 📩 Automatic detection of new incoming SMS
- 🔎 SMS search & preview
- 🗑️ Safe manual message deletion
- 📊 SMS storage/capacity monitoring
- 🖥️ Modern Persian RTL interface
- 🔄 Background polling for new messages
- 🛡️ No automatic message deletion

👉 **[View the project →](https://github.com/ashkan0033/ZTE-U10S-Pro-SMS-Manager)**
