## 🚀 Featured Project

### 📱 ZTE U10S Pro SMS Manager

A standalone Windows application that communicates directly with the **ZTE U10S Pro modem API** to manage SMS without depending on the modem's browser interface.

**Built with:** Python • PySide6 • HTTP/API • JSON • Authentication • Background polling

**Highlights:**

- 🔐 Challenge/hash authentication flow
- 📩 Automatic new-SMS detection
- 🔎 Search & preview
- 🗑️ Safe manual deletion
- 📊 SMS capacity monitoring
- 🖥️ Persian RTL interface
- 🔄 Background polling
- 🛡️ No automatic message deletion
